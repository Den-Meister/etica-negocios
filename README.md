# Ética de los Negocios — Guía de estudio

Guía de estudio del ramo Ética de los Negocios (UDD, Sección 4).
Página estática de un solo archivo: `index.html`.

## Cómo publicarla en GitHub Pages

1. Crea un repositorio nuevo en GitHub (ej. `etica-negocios`).
2. Sube `index.html` (y este `README.md`) a la rama `main`.
3. En el repo: **Settings → Pages**.
4. En **Build and deployment → Source**, elige **Deploy from a branch**.
5. Branch: `main` · carpeta: `/ (root)` · **Save**.
6. En ~1 minuto queda online en:
   `https://<tu-usuario>.github.io/<nombre-del-repo>/`

## Actualizar la guía

Es una página estática: cada vez que haya una versión nueva de `index.html`,
reemplaza el archivo en el repo y haz commit. GitHub Pages actualiza solo.

## Notas

- El único cambio respecto al archivo original fue el nombre: `index.html`
  (GitHub Pages carga ese archivo como página principal).
- Las fuentes se cargan desde Google Fonts (CDN); requiere conexión.
- Un repo **público** deja la página visible para cualquiera con el link.
  Para mantenerla **privada** necesitas un plan pago de GitHub (Pages en repos
  privados). Alternativa gratis y privada: dejarla solo como archivo local.
